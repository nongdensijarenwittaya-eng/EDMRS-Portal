# คู่มือผู้ดูแลระบบ (Admin Guide) - EDMRS

## 1. การจัดการสิทธิ์ผู้ใช้งาน (RBAC)
1. เข้าสู่ระบบด้วยสิทธิ์ **Super Admin** (`admin` / `admin123`)
2. ไปที่เมนู **"ผู้ใช้งาน & สิทธิ์การเข้าถึง"**
3. สามารถเพิ่มบัญชีผู้ใช้ใหม่ และเลือกกำหนดสิทธิ์ได้ 4 บทบาท:
   - **Super Admin**: สิทธิ์สูงสุด
   - **Administrator**: นายทะเบียน/ผู้บริหาร
   - **Staff**: เจ้าหน้าที่ทะเบียน
   - **Viewer**: ดูข้อมูลได้อย่างเดียว

---

## 2. การตรวจสอบประวัติการใช้งาน (Audit Logs)
1. ไปที่เมนู **"ประวัติการแก้ไข (Audit Log)"**
2. ตรวจสอบวัน-เวลา, ชื่อผู้ใช้งาน, โมดูลการทำงาน, IP Address และรายละเอียดการแก้ไขข้อมูล
3. สามารถส่งออกไฟล์ Audit Log เป็น Excel ได้

---

## 3. การกู้คืนและสำรองข้อมูล (Backup & Restore)
1. ไปที่เมนู **"ตั้งค่าระบบ"**
2. หัวข้อ **"ระบบสำรองข้อมูล & เรียกคืนฐานข้อมูล"**
3. คลิก **"ดาวน์โหลดไฟล์สำรอง (.json)"** เพื่อเก็บไฟล์ Backup
