# วิธีเพิ่มประเภทเอกสาร ปพ. ใหม่ (Add Document Types) - EDMRS

## ขั้นตอนการเพิ่มประเภทเอกสาร (Dynamic Doc Types)
1. ไปที่เมนู **"ทะเบียนเอกสาร ปพ."**
2. คลิกปุ่ม **"จัดการประเภทเอกสาร"**
3. กรอก **รหัสประเภท** (เช่น `ปพ.10`) และ **ชื่อเอกสาร**
4. คลิกปุ่ม **"เพิ่มประเภทเอกสาร"**
5. ระบบจะบันทึกประเภทเอกสารใหม่ลงในระบบ และสามารถเลือกใช้งานในฟอร์มลงทะเบียนได้ทันที
