# วิธีสร้างบัญชีผู้ดูแลระบบ (Create Admin Account) - EDMRS

## ขั้นตอนการสร้างบัญชี Admin
1. เข้าสู่ระบบด้วยบัญชี **Super Admin** เดิม (`admin` / `admin123`)
2. คลิกเมนู **"ผู้ใช้งาน & สิทธิ์การเข้าถึง"** ในแถบเมนูข้าง (Sidebar)
3. คลิกปุ่ม **"เพิ่มผู้ใช้งานใหม่"**
4. กรอกข้อมูลชื่อผู้ใช้ รหัสผ่าน ชื่อ-นามสกุล และเลือกบทบาท (Role) เป็น **Administrator** หรือ **Super Admin**
5. คลิก **"สร้างบัญชี"**
6. ระบบจะบันทึกประวัติการสร้างลงใน Audit Log โดยอัตโนมัติ
