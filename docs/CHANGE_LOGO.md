# วิธีเปลี่ยน Logo สถานศึกษา (Change Logo Guide) - EDMRS

## ขั้นตอนการเปลี่ยน ตราสัญลักษณ์ / Logo
1. เข้าสู่ระบบด้วยสิทธิ์ **Admin**
2. ไปที่เมนู **"ตั้งค่าระบบ"**
3. ในการ์ด **"ข้อมูลสถานศึกษา & โลโก้"** ให้แก้ไขช่อง **"URL รูปตราสัญลักษณ์ / Logo"** หรือระบุที่อยู่ไฟล์เช่น `assets/logo.png`
4. คลิกปุ่ม **"บันทึกการตั้งค่าสถานศึกษา"**
5. ตราสัญลักษณ์ใน Header แดชบอร์ดและหน้า Login จะเปลี่ยนเป็นตราสัญลักษณ์ใหม่ทันที
