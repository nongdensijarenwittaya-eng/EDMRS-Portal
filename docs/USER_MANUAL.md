# คู่มือการใช้งานสำหรับเจ้าหน้าที่ (User Manual) - EDMRS

## 1. การเข้าสู่ระบบ (Login)
1. เข้าสู่หน้าจอเข้าสู่ระบบ
2. กรอก **ชื่อผู้ใช้งาน** และ **รหัสผ่าน**
   - ตัวอย่างสิทธิ์ Staff: `staff` / `staff123`
3. คลิกปุ่ม **เข้าสู่ระบบ**

---

## 2. การค้นหาเอกสารแบบรวมศูนย์ (Central Deep Search)
1. ในหน้าแดชบอร์ด กรอกคำค้นหาในช่องค้นหาขนาดใหญ่ (เช่น รหัสนักเรียน `65001234`, ชื่อ `สมชาย`, หรือ Location Code `LOC-A03-02-04`)
2. ระบบจะแสดงผลลัพธ์ทันที แยกตามรายชื่อนักเรียนและเอกสาร ปพ.
3. คลิกปุ่ม **"ผังตำแหน่ง"** เพื่อดูเส้นทางนำทางไปยังตู้/แฟ้มจัดเก็บจริง

---

## 3. การบันทึกยืม–คืนเอกสาร
1. ไปที่เมนู **"ระบบยืม–คืนเอกสาร"**
2. คลิก **"บันทึกการยืมเอกสารใหม่"**
3. เลือกเอกสารที่ต้องการยืม และกรอกชื่อผู้ยืมพร้อมเหตุผล
4. ระบบจะเปลี่ยนสถานะเอกสารเป็น **"ยืมออก"** อัตโนมัติ
5. เมื่อผู้ยืมนำเอกสารมาคืน ให้คลิกปุ่ม **"รับคืนเอกสาร"** เพื่อสลับสถานะกลับเป็น **"จัดเก็บแล้ว"**

---

## 4. การเพิ่มไฟล์สแกนดิจิทัล (PDF, JPG, PNG)
การเพิ่มไฟล์สแกนดิจิทัลลงในทะเบียนเอกสาร ปพ. สามารถทำได้ 3 ช่องทางสะดวก:

1. **อัปโหลดไฟล์จากเครื่อง/มือถือ**:
   - ในฟอร์มเพิ่ม/แก้ไขเอกสาร คลิกปุ่ม **"1. เลือกไฟล์ (PDF/JPG/PNG)"**
   - เลือกไฟล์เอกสารสแกนจากเครื่องหรือโทรศัพท์มือถือ (รองรับไฟล์ PDF, JPG, JPEG, PNG ขนาดไม่เกิน 10MB)

2. **สแกนด้วยกล้องมือถือ/เว็บแคม (Mobile/Webcam Scanner)**:
   - คลิกปุ่ม **"2. ถ่ายสแกนด้วยกล้องมือถือ/เว็บแคม"**
   - นำเอกสาร ปพ. ฉบับจริงจัดวางให้อยู่ในกรอบสี่เหลี่ยม แล้วกดปุ่ม **"ถ่ายภาพเอกสาร (Capture Document)"** ระบบจะแปลงภาพถ่ายเป็นไฟล์สแกนดิจิทัลสำหรับจัดเก็บทันที

3. **รับภาพจากเครื่องปริ้นต์/สแกนเนอร์ (Printer/Scanner Device)**:
   - คลิกปุ่ม **"3. ดึงภาพจากเครื่องสแกนเนอร์"** เพื่อเชื่อมต่อสัญญาณภาพจากเครื่องสแกนเนอร์/เครื่องพิมพ์มัลติฟังก์ชัน

## 5. การจัดการอัลบั้มใน Google Drive และการซิงก์ Google Sheets
1. **การดูอัลบั้มประจำเล่มใน Google Drive**:
   - ไปที่เมนู **"ทะเบียนเล่มเอกสาร"**
   - บนการ์ดแต่ละเล่มเอกสาร ให้คลิกปุ่ม **"อัลบั้มไดร์ฟประจำเล่ม"**
   - ระบบจะเปิดหน้าต่างแสดงไฟล์สแกนทั้งหมดที่จัดเก็บอยู่ในโฟลเดอร์อัลบั้มของเล่มนั้นใน Google Drive (`Google Drive/EDMRS_Vault/[BOOK_CODE]/`)

2. **การซิงก์ฐานข้อมูลลง Google Sheets**:
   - ในหน้า **"ทะเบียนเล่มเอกสาร"** หรือ **"ตั้งค่าระบบ"** ให้คลิกปุ่ม **"ซิงก์ไปที่ Google Sheets"**
   - ระบบจะทำการส่งข้อมูลตารางทะเบียนเอกสาร ปพ. รายชื่อนักเรียน และเล่มเอกสารไปอัปเดตลง Google Sheets ในชีทการตั้งค่า
