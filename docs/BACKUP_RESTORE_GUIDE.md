# วิธีการสำรองและกู้คืนฐานข้อมูล (Backup & Restore Guide) - EDMRS

## การสำรองข้อมูล (Backup Database)
1. เข้าสู่ระบบด้วยบัญชี **Super Admin**
2. ไปที่เมนู **"ตั้งค่าระบบ"**
3. ที่การ์ด **"ระบบสำรองข้อมูล & เรียกคืนฐานข้อมูล"** คลิกปุ่ม **"ดาวน์โหลดไฟล์สำรอง (.json)"**
4. ระบบจะทำการ Export ข้อมูลทั้งหมดในฐานข้อมูลเป็นไฟล์ JSON Dump ลงในเครื่องคอมพิวเตอร์ของคุณ

## การกู้คืนข้อมูล (Restore Database)
1. ไปที่เมนู **"ตั้งค่าระบบ"**
2. คลิกปุ่ม **"นำเข้าไฟล์ Restore Database"**
3. เลือกไฟล์สำรอง `.json` ที่ต้องการกู้คืน
4. ยืนยันการกู้คืนข้อมูล ระบบจะทำการอัปเดตและแสดงข้อมูลตามไฟล์สำรองทันที
